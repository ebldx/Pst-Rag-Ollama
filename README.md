# Retrieval-augmented Generation with .pst files
Retrieval augmented generation with Outlook backup files using Python.

- [Installation](##Installation)
- [Usage](##Usage)

## Installation
### Prerequisites:
- Python 3.14
- Pip
- Ollama
### Using GitHub CLI:
```
  // Ensure that python is version 3.14.
  python --version

  pip install ollama Aspose.Email-for-Python-via-NET
  gh repo clone ebldx/Pst-Rag-Ollama
```

## Usage
First export your outlook data to a .pst file. Ensure that ollama is running in the background or run `ollama serve` to be safe. Finally, in the Pst-Rag-Ollama directory, run `python src/pst-rag-ollama/main.py` and follow the instructions in the terminal.
